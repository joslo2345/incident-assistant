# inc-2025008: Rising ECC errors on a100-node-03 GPU 1

## Summary
XID 92 (high single-bit ECC error rate) on GPU 1; 93 correctable errors in the last hour. Severity sev3. Resolved in 68.6 hours.

## Timeline
- 2025-02-28 22:45 UTC: XID 92 (high single-bit ECC error rate) on GPU 1; 93 correctable errors in the last hour.
- 23:13 UTC: on-call acknowledged and started diagnosis.
- 2025-03-03 19:19 UTC: resolved.

## Root cause
Single bad row on GPU 1; pending remap had not been applied.

## Resolution
Drained and reset the GPU; remap applied; no further errors over 30 days.

## Lessons
Check remapped_rows.pending first; a reset alone often fixes an isolated row.
