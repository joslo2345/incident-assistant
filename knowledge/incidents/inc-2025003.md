# inc-2025003: GPU 2 fell off the bus on h100-node-02

## Summary
BMC PCIe fatal error on GPU slot 2 followed by XID 79; lspci showed the device missing. Severity sev1. Resolved in 13.7 hours.

## Timeline
- 2025-01-26 04:36 UTC: BMC PCIe fatal error on GPU slot 2 followed by XID 79; lspci showed the device missing.
- 04:45 UTC: on-call acknowledged and started diagnosis.
- 2025-01-26 18:17 UTC: resolved.

## Root cause
GPU 2 hardware fault (serial 1693108383355).

## Resolution
Rebooted; GPU failed DCGM level 3; replaced under RMA.

## Lessons
Always run DCGM level 3 after an XID 79 recovery before resuming.
