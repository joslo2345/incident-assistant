# inc-2025051: Power capping on h100-node-03 after PSU loss

## Summary
All GPUs on h100-node-03 dropped to a 420 W enforced limit; BMC reported PSU4 input lost. Severity sev2. Resolved in 4.2 hours.

## Timeline
- 2025-12-04 21:59 UTC: All GPUs on h100-node-03 dropped to a 420 W enforced limit; BMC reported PSU4 input lost.
- 22:23 UTC: on-call acknowledged and started diagnosis.
- 2025-12-05 02:10 UTC: resolved.

## Root cause
Power cap left in place after a facility event the week before.

## Resolution
Removed the manual cap with nvidia-smi -pl; no hardware fault.

## Lessons
Record every manual cap with an end condition; forgotten caps look like PSU faults.
