# inc-2025023: Power capping on h100-node-04 after PSU loss

## Summary
All GPUs on h100-node-04 dropped to a 420 W enforced limit; BMC reported PSU1 input lost. Severity sev3. Resolved in 6.1 hours.

## Timeline
- 2025-08-03 06:24 UTC: All GPUs on h100-node-04 dropped to a 420 W enforced limit; BMC reported PSU1 input lost.
- 06:53 UTC: on-call acknowledged and started diagnosis.
- 2025-08-03 12:32 UTC: resolved.

## Root cause
PSU1 lost input: PDU outlet breaker tripped.

## Resolution
Datacenter operations reset the breaker; limits returned to default automatically.

## Lessons
Check the PDU before replacing a PSU; two other nodes on the same PDU were affected.
