# inc-2025030: Power capping on h100-node-02 after PSU loss

## Summary
All GPUs on h100-node-02 dropped to a 420 W enforced limit; BMC reported PSU3 input lost. Severity sev3. Resolved in 5.5 hours.

## Timeline
- 2025-04-13 11:37 UTC: All GPUs on h100-node-02 dropped to a 420 W enforced limit; BMC reported PSU3 input lost.
- 11:51 UTC: on-call acknowledged and started diagnosis.
- 2025-04-13 17:05 UTC: resolved.

## Root cause
PSU3 module failed.

## Resolution
Hot-swapped PSU3 from spares; enforced limits back to default.

## Lessons
No drain needed for a PSU swap on redundant chassis.
