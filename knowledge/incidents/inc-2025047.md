# inc-2025047: PCIe replays on h100-node-04 GPU 1

## Summary
PCIe replay counter on GPU 1 rising 231 per minute; data loading slowed. Severity sev3. Resolved in 14.4 hours.

## Timeline
- 2025-03-12 04:00 UTC: PCIe replay counter on GPU 1 rising 231 per minute; data loading slowed.
- 04:28 UTC: on-call acknowledged and started diagnosis.
- 2025-03-12 18:25 UTC: resolved.

## Root cause
Riser not fully seated after maintenance.

## Resolution
Reseated the riser; link back at x16 Gen5, counter flat.

## Lessons
Check LnkSta against LnkCap after every service visit.
