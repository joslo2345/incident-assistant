# inc-2025059: GPU 0 fell off the bus on a100-node-02

## Summary
BMC PCIe fatal error on GPU slot 0 followed by XID 79; lspci showed the device missing. Severity sev1. Resolved in 15.2 hours.

## Timeline
- 2025-07-15 08:44 UTC: BMC PCIe fatal error on GPU slot 0 followed by XID 79; lspci showed the device missing.
- 09:02 UTC: on-call acknowledged and started diagnosis.
- 2025-07-15 23:54 UTC: resolved.

## Root cause
Driver bug in an old driver version, triggered by a specific workload.

## Resolution
Rebooted; upgraded the driver fleet-wide after canary testing.

## Lessons
Check the driver release notes when XID 79 appears on several nodes with healthy hardware.
