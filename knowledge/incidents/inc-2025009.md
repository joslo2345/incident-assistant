# inc-2025009: Power capping on h100-node-03 after PSU loss

## Summary
All GPUs on h100-node-03 dropped to a 420 W enforced limit; BMC reported PSU3 input lost. Severity sev2. Resolved in 6.0 hours.

## Timeline
- 2025-10-23 00:53 UTC: All GPUs on h100-node-03 dropped to a 420 W enforced limit; BMC reported PSU3 input lost.
- 01:10 UTC: on-call acknowledged and started diagnosis.
- 2025-10-23 06:56 UTC: resolved.

## Root cause
PSU3 lost input: PDU outlet breaker tripped.

## Resolution
Datacenter operations reset the breaker; limits returned to default automatically.

## Lessons
Check the PDU before replacing a PSU; two other nodes on the same PDU were affected.
